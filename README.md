# BIOS CLI releases

This public repository distributes verified BIOS CLI release archives. The CLI source, tests, and release workflow are maintained in the private `bio-xyz/bios-monorepo` monorepo.

## Install

```sh
curl -fsSL https://ai.bio.xyz/install | sh
```

Supported packages: Linux x64, Linux ARM64, and Apple-silicon macOS. Intel macOS is not currently published.

> The current macOS prerelease is not signed or notarized and may be blocked by Gatekeeper. BIOS does not recommend bypassing Gatekeeper.

See [Releases](https://github.com/bio-xyz/bios-cli/releases) for manual downloads and SHA-256 checksum files.
